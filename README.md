# Smart-Purple-Pillbox
Smart pillbox for elderly with gentle alarm and SOS - Graduation Project

### 🎯 Idea
علبة دواء ذكية لكبار السن بتنبههم بمعاد الدواء بنغمة هادية ونور، ولو نسيوا بتسجل عدد المرات اللي نسيوا فيها، وفيها زرار SOS للطوارئ.

### 🛠️ Components
- ESP32
- DS3231 RTC Module (Real Time Clock)
- OLED Display 128x64
- Buzzer
- LEDs
- Push Buttons & Switches
- Purple Acrylic Box
